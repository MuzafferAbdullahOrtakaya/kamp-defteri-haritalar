# Kamp Defteri · internetsiz arazi haritaları

Kamp Defteri uygulamasının il il indirilen internetsiz harita paketleri.
Dosyalar "Releases" bölümünde durur; uygulama gerektiğinde buradan indirir.

Her il için dört dosya:
- `<il>_harita.pmtiles`: yollar, patikalar, dereler, yerleşimler (OpenStreetMap, Protomaps)
- `<il>_egri.pmtiles`: eş yükselti çizgileri
- `<il>_golge.pmtiles`: dağ gölgelendirmesi
- `<il>_dem.pmtiles`: 3B görünüm ve yükseklik için arazi verisi
